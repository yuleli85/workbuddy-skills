# 页型字段说明

所有页都可加：`section`（分节名）、`notes`（演讲备注）。文字字段都支持 `**加粗**` 和 `\n` 换行。
建议字数是「放得下且好看」的量，超了脚本会先缩字号，再超会提醒。

## cover 封面
```json
{ "type": "cover", "title": "主标题\n可以两行", "subtitle": "一句话副标题", "icon": "FaSyncAlt", "meta": "技术部 · 2026 年 10 月" }
```
标题每行 12 字内，最多两行；副标题 30 字内。`icon`、`meta` 可不写。

## statement 一句话大字
```json
{ "type": "statement", "text": "一页只说一件事，**标题就是结论**", "sub": "补充一句" }
```
用来强调关键结论或做章节过渡。`text` 30 字内。

## flow 流程 / 闭环
```json
{ "type": "flow", "title": "……", "intro": "上方说明框（可不写）",
  "steps": [ { "name": "执行", "icon": "FaPlay", "desc": "可不写", "key": true } ],
  "note": "下方一句总结（可不写）", "arrows": true }
```
3～7 步；`name` 4 字内；`desc` 15 字内；`key` 的圈变橙色。没写 `icon` 时圈里显示序号。

## cards 卡片墙
```json
{ "type": "cards", "title": "……", "columns": 4, "numbered": true, "style": "outline",
  "items": [ { "name": "自动评估", "desc": "规则、模型、人工三层", "icon": "FaBalanceScale", "key": true } ],
  "legend": "橙色为最关键的三项", "note": "无重点项时可写一句页脚说明" }
```
- 2～10 项；不写 `columns` 时自动分列（≤4 一行，5～6 三列，7～8 四列，9～10 五列）。
- 一排只有 2～4 张时自动放大成大卡。
- `style`：不写是浅底色块，`"outline"` 是白底描边带阴影（适合「特征」「原则」这类）。
- `numbered`：右上角显示 01、02……
- `layout`：一般不写，脚本按字数自动选「图标在上」或「图标和名字同一行」；要固定就写 `"stack"` 或 `"inline"`。
- `name` 8 字内；`desc` 五列时 12 字内，四列 30 字内，三列及以下 40 字内。

## table 表格
```json
{ "type": "table", "title": "10 项功能详解", "numbered": true, "fontSize": 12,
  "columns": [ { "name": "功能", "width": 2 }, { "name": "要做到什么", "width": 4.5 }, { "name": "缺了会怎样", "width": 2.5, "color": "warn" } ],
  "rows": [ ["全程轨迹记录", "每次任务记下……", "没有原料……"] ],
  "keyRows": [2, 4], "note": "橙色底为重点" }
```
- `width` 是相对比例，自动换算到整页宽。`color` 可选 `warn`（红）、`primary`（主色）、`muted`（灰），整列文字用这个色。
- 第一列自动加粗；`keyRows` 是从 0 数的行号，整行橙色底。
- 行多放不下时自动拆成几页，标题后加（1/2）（2/2），尽量每页行数均匀。
- 3～4 列最合适；单元格 60 字内。

## panels 大面板
```json
{ "type": "panels", "title": "……",
  "items": [ { "name": "看板", "icon": "FaChartLine", "desc": "按周看趋势，盯住五个数：", "bullets": ["一次通过率", "返工率"] } ] }
```
2～3 块；每块 `bullets` 6 条内，每条 12 字内。

## levels 台阶分级
```json
{ "type": "levels", "title": "成熟度分级：建议先做到 L3", "target": 3, "note": "**建议目标定在 L3**\nL4 等数据攒够再做",
  "items": [ { "level": "L0", "state": "固定提示词，不记任何东西", "human": "人：全靠人改" } ] }
```
3～6 级，台阶从左到右升高；`target` 是从 0 数的目标级，橙色；最高一级用浅色。`note` 放左上角空白处，两行内。

## compare 左问题右对策
```json
{ "type": "compare", "title": "常见的坑和对策", "left": "坑", "right": "对策",
  "rows": [ { "name": "记忆膨胀", "desc": "只进不出，上下文越来越长", "answer": "检索后拼装＋合并＋淘汰" } ] }
```
2～6 行；`name` 8 字内，`desc` 20 字内，`answer` 30 字内。`left`/`right` 默认「问题」「对策」。

## steps 分步走
```json
{ "type": "steps", "title": "落地建议：分三步走", "emphasizeFirst": true,
  "items": [ { "name": "打底", "tag": "单场景", "body": "做法，50 字内", "point": "要点，30 字内（可不写）" } ] }
```
2～4 步；第一步默认深色突出，不要就写 `"emphasizeFirst": false`。

## bullets 要点
```json
{ "type": "bullets", "title": "……", "fontSize": 18,
  "items": [ "第一条", { "text": "第二条", "sub": ["子项一", "子项二"] } ],
  "callout": "右侧深色框里的一句重点（可不写）" }
```
6 条内，每条 30 字内。字多会自动缩到 12 号为止。

## image 图片
```json
{ "type": "image", "title": "……", "path": "截图.png", "caption": "图注（可不写）" }
```
`path` 相对稿子文件；按原比例放到最大并居中。支持 png、jpg。

## closing 结尾
```json
{ "type": "closing", "title": "一句话：先挑一个场景，把闭环跑通", "subtitle": "最先要做实的三项",
  "items": [ { "name": "自动评估", "desc": "先能分清好坏", "icon": "FaBalanceScale" } ] }
```
`items` 1～4 项；不写 `items` 时标题放大居中（适合「谢谢」「欢迎提问」）。

## custom 自定义页
```json
{ "type": "custom", "title": "……", "script": "自定义页.js", "任意字段": "原样传给脚本" }
```
脚本导出 `async (slide, ctx, d) => {}`，标题已经放好。可用的：
- `ctx.t`：当前配色（见下），`ctx.pres.shapes`：形状名；
- `ctx.text(slide, 文字, {x,y,w,h}, {fontSize, minSize, bold, color, align, valign, name})`：按框放字、自动缩；
- `ctx.icon(slide, "FaRocket", {x,y,w,h}, 颜色)`；
- `ctx.warn("……")`：加一条版面提醒。
版面是 10 × 5.625 英寸，内容区 x 从 0.5 到 9.5，y 从 1.15 到 5.1。参考 `examples/自定义页.js`。

## 配色字段
`theme` 写成对象时可改这些色（六位十六进制，`#` 可带可不带）：

| 色名 | 用在哪 |
|---|---|
| `primary` | 主色：图标圈、强调字、表头以外的重点 |
| `highlight` | 重点项：橙色卡、目标级、箭头 |
| `dark` | 深色：封面底、标题字、表头 |
| `text` | 正文字 |
| `soft` | 浅底：卡片、面板 |
| `line` | 边线、浅色字 |
| `muted` | 灰字：页码、注释 |
| `light` | 次要强调：编号 |
| `warn` | 警示：问题列、「缺了会怎样」 |
| `darkCard` | 深色页上的卡片底 |
| `warnSoft` | 问题格浅底 |
| `highlightSoft` | 重点行浅底 |

还可写 `font`（默认 `Microsoft YaHei`）和 `name`（主题名，PowerPoint 里显示）。
