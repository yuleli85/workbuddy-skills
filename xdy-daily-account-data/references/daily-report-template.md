## 三、跨日结论基线（已论证，后续报告直接引用不必重推）

### 3.1 平台机制不同 → 不能用一套节奏运营

| 平台 | 机制 | 已验证的现象 |
|---|---|---|
| 小红书 | 推荐流，曝光对「是否更新」高度敏感 | 停更 3 天曝光从 206 → 39（-81%）；复更次日回 156（+300%）。同期**封面点击率稳定在 12~19% 未动** → 掉量源于停更，非内容退步 |
| 知乎 | 搜索 / 长尾，发新不抬旧 | 10-08 峰值 567 → 连续下滑至 10-14 的 12（-98%），期间 10-12 发过新内容但未止跌；老文长尾走完就一路向下 |
| 抖音 | 推荐 + 更新权重 | 10-11 ~ 10-14 连续 4 天零发布，播放量同步走低（灵创号 37 → 7 → 9 → 4）。当前瓶颈是"没有内容"，不是内容质量 |

**这条基线的用法**：看到流量下滑，先分「内容变差」还是「平台不给量」。若是后者（质量类指标稳定 + 发布量低），结论直接指向恢复更新频率，不要绕到内容优化。

### 3.2 数据时效性

| 事实 | 含义 |
|---|---|
| 服务端约 **17:50** 刷新 | 白天手动跑当日数据天然不全，属正常 |
| `trend_update_time` 变成今天 ≠ 今天有数据点 | 判到位看 `max(date)` + 当日行数是否满额（约 96 行） |
| 服务端会**回改仍在 7 天窗口内的旧日期** | 所以采集器固定拉逐日曲线（`--trend-flag 1`）而非区间汇总，否则拼不成时间序列、且改不动 |
| 补拉一轮常能多拿数据 | 实测 +39 行趋势 / +3 条作品；也曾把前一轮的「播放 0 / 发布 0」纠正为「11 / 1」 |

### 3.3 内容侧口径

- 抖音作品表提供**单条** `bounce_rate_2s` / `completion_rate_5s` / `avg_view_time` —— 本团队唯一能直接指导「前 3 秒」优化的量化口径。
- **必须按 `duration_sec` 分层**：15 秒竖屏短片 vs 100 秒以上宣传片，口径不可混比。
- **`playCount` 未上百不下结论**（实测同一条作品从 3 次播放到 20 次播放，读数从 `50%/50%` 翻成 `58.6%/3.4%`）。
- 截至 10-14，抖音窗口内作品**全部为 54~177 秒长片，无 ≤20 秒样本** → 「15 秒竖屏」这条线尚无数据支撑，不要用长片数据外推。
