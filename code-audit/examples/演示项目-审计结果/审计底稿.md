### DEP-KNOWN-VULN　有已知漏洞的组件版本（严重，1 处）

处理办法：yaml.load 可远程执行代码（CVE-2020-14343）；升级到 5.4 或更高

- `S-7e7fc2` requirements.txt　`pyyaml PyYAML==5.3.1`

### SEC-DESERIALIZE　反序列化不可信数据，可能被远程执行代码（高，1 处）

处理办法：外部来的数据只用 JSON 这类纯数据格式；YAML 用 safe_load；fastjson 关掉 autoType 或换 fastjson2。

- `S-c66162` app.py:78　`data = yaml.load(request.data)`

### SEC-HARDCODED-SECRET　口令或密钥写死在代码里（高，1 处）

处理办法：改成从环境变量或配置中心读取，代码和仓库里只留示例值；已提交过的真实口令要换掉。

### SEC-SQL-FORMAT　SQL 用字符串格式化拼参数，可能被注入（高，1 处）

处理办法：改用参数化：cursor.execute("... where id=%s", (id,)) 或 ORM 查询；不要用 f-string / % / format 拼 SQL。

- `S-a3d73a` services/order.py:33　`sql = f"select o.* from orders o join order_items i on i.order_id = o.id where o.user_id = {user_id} and i.name like '%{keyword}%'"`
